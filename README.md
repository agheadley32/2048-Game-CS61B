# 2048 Game - CS61B
## 🎮 Overview
This is a Java implementation of the **2048 Game**, developed for my UC Berkeley **CS61B** course.  
The game challenges players to combine numbered tiles on a 4x4 grid to reach the **2048** tile.

## 🧠 Features
- Arrow key controls (Up, Down, Left, Right)
- Tile merging and score tracking
 - Win and Game Over detection
  - Restart functionality
   - Simple and responsive user interface

## 🛠️ How to Run
1. Open the project in **IntelliJ IDEA**.
2. Run the `Main` class to start the game.
3. Use your arrow keys to move the tiles.
4. Try to reach the **2048** tile!

## 📄 How It Works
- The game uses a **2D array** to represent the board.
- Tiles merge when they have the same value and move in the same direction.
- After every move, a new tile (2 or 4) spawns randomly.
- The game ends when no moves are possible.
